# Как работает эта система?

Приложения вроде Omegle и WhatsApp обычно общаются без постоянного сервера посередине. Эта система работает по похожей идее.

Интернет-провайдеры могут не разрешать открывать TCP-порты, но могут разрешать UDP-порты.

В этом моде связь сервера Minecraft, которая обычно работает через TCP, переносится через UDP и показывается другой стороне так, будто это TCP.

Это позволяет тебе бесплатно и плавно играть с другом без прохождения трафика через relay-сервер.

Например, в похожих модах:

`Твой компьютер (Стамбул) -> relay-сервер (Франкфурт) -> компьютер твоего друга (Стамбул)`

В этом моде:

`Твой компьютер (Стамбул) -> компьютер твоего друга (Стамбул)`

Посередине нет сервера для игрового трафика.

Связь идет только между тобой и твоим другом.

Этот мод использует сервер только для того, чтобы обе стороны могли узнать IP-адрес друг друга.

## Безопасность

- Используются проверки CodeQL
- Платформы вроде CurseForge могут сканировать новые версии
- Ты можешь посмотреть сборки
- Сборки загружаются через GitHub Actions, а не вручную с моего компьютера
