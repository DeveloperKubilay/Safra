# 这个系统是怎么工作的？

像 Omegle 和 WhatsApp 这样的应用，通常并不会一直把服务器放在中间转发通信。这个系统也是类似的思路。

网络提供商可能不允许开放 TCP 端口，但可能允许 UDP 端口。

在这个 Mod 里，原本通过 TCP 运行的 Minecraft 服务器通信会被放到 UDP 上传输，并在另一端表现得像 TCP 一样。

这样你就可以免费、顺畅地和朋友一起玩，而且游戏流量不需要经过中继服务器。

比如在一些类似的 Mod 里：

`你的电脑（伊斯坦布尔） -> 中继服务器（法兰克福） -> 你朋友的电脑（伊斯坦布尔）`

而在这个 Mod 里：

`你的电脑（伊斯坦布尔） -> 你朋友的电脑（伊斯坦布尔）`

游戏流量中间没有服务器。

通信只发生在你和朋友之间。

这个 Mod 只会在双方互相查找 IP 地址时使用服务器。

## 安全性

- 使用了 CodeQL 扫描
- CurseForge 之类的平台可能会扫描新版本
- 你可以查看构建结果
- 构建通过 GitHub Actions 上传，而不是我从自己的电脑手动上传
