# 这个系统是怎么工作的？

像 WhatsApp（通话时）、Omegle 或 BitTorrent 这样的应用，通常会采用 **P2P（Peer-to-Peer / 点对点）** 技术，而不是将所有流量都通过中央服务器转发。将数百万玩家的游戏数据全部经过中央服务器，不仅会导致极高的网络延迟（卡顿），还会产生巨大的服务器成本。

### 系统具体是如何运作的？

1. 通常情况下，家用宽带是没有开放公网端口的（由于 IPv4 地址枯竭以及运营商使用 CGNAT，无法直接从外部开放端口）。
2. 但是，每当你访问某个网站或向外发起网络请求时，你的路由器/运营商都会临时对外打开一个出口端口。
3. 在这个系统里，Mod 会像要访问 Google 等网站一样建立连接，但并不发送网页数据；它只是获取这个临时打开的端口并分享给你的朋友，同时把朋友的端口信息提供给你。这就像是说 *"我要去访问一个网站"*，然后利用这个打开的端口直接与你的朋友建立连接。
4. 连接一旦建立，游戏通信就**无需经过任何中间服务器**，直接在你的电脑和朋友的电脑之间（P2P）高速传输。

---

### 连接方式对比

比如在一些类似的 Mod 里：

`你的电脑（伊斯坦布尔） -> 中继服务器（法兰克福） -> 你朋友的电脑（伊斯坦布尔）`

而在这个 Mod 里：

`你的电脑（伊斯坦布尔） -> 你朋友的电脑（伊斯坦布尔）`

中间没有任何中继服务器，所有通信完全发生在你和朋友之间。
