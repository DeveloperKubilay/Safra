**最后更新：** 2026年11月14日

Safra 是一款 Minecraft（我的世界）模组，允许玩家通过直接的点对点（P2P）连接一起游戏，无需租用或搭建专用的中央游戏服务器。我们**绝不会为了广告、数据分析或任何商业目的向第三方出售、出租或分享您的数据。**

---

## 1. 我们处理哪些数据以及记录的原因

为了使模组能够正常运行、进行玩家匹配，并**保护我们的基础设施免受 DDoS 攻击与滥用，以及在法律上进行合规防御**，我们仅处理以下必要的技术数据：

- **IP 地址：** 用于 P2P 匹配连接、限制来自同一 IP 的过度请求（Rate-limiting），并在发生 DDoS 攻击或恶意滥用时防御服务器安全；记录在服务器访问日志中。
- **临时端口信息：** 在会话匹配期间处理，以便房主与加入的玩家之间建立直接网络连接。
- **会话代码与可选的世界代码：** 用于将正确的玩家连接到对应的游戏会话；会话代码会记录在访问日志中。
- **中继请求与 RelayId：** 当直接 P2P 打洞失败时（例如严格的 NAT/CGNAT 环境），用于建立加密的 TURN / Bedrock Relay 备用中继并监控潜在滥用行为。
- **User-Agent（Safra、Minecraft、模组加载器及 Java 版本）：** 用于验证请求来自官方且兼容的模组版本，协助排查问题，并区分正常流量与自动化脚本或攻击。
- **时间戳与 Cloudflare `Ray` ID：** 保存在服务器访问日志中，用于在发生 DDoS 攻击或技术故障时分析网络流量。

出于系统安全和防范 DDoS 攻击而保留的服务器访问日志，将在维护系统安全以及应对网络攻击所需的时间内妥善保存。

## 2. 我们绝不收集或记录的数据

Safra **绝不**收集、读取或记录以下任何内容：
- 密码、Minecraft / 微软账户凭据或身份验证 Token
- 个人身份或联系方式（姓名、电子邮箱、电话号码等）
- 游戏内聊天消息、指令或语音聊天音频内容
- 您安装的其他模组列表、世界存档文件（saves）、物品栏数据或任何游戏内事件

---

## 3. P2P 连接、IP 泄露与代码安全（免责声明）

- **传输 IP 与端口在技术上是必需的：** Safra 在玩家之间直接传输游戏网络流量（P2P）。为了让收到您会话代码的朋友能够加入您的游戏，您的 IP 地址和端口信息在技术上必须共享给对方。
- **仅与信任的朋友一起游戏：** 基于 P2P 网络的固有特性，您所连接或邀请到您世界的玩家能够看到您的 IP 地址。**因向不可信人员分享代码或在公开平台发布代码而导致的 IP/端口泄露或潜在的网络攻击，Safra 及其开发者概不承担任何责任。** 请务必仅与您信任的朋友一起游戏。
- **代码不可预测性：** 会话代码采用密码学安全的随机生成器生成，长度为 12 位字符（固定代码模式下为 16 位字符），具有超过 $32^{12}$ 种可能的组合。除非您主动分享代码，否则第三方在理论和实际上都几乎无法猜出或发现您的会话。

---

## 4. 第三方基础设施（免责声明）

您的数据绝不会出于商业目的转让给第三方；但为了保证功能正常，模组必须与以下技术基础设施提供商进行通信：
- **Cloudflare：** 用于信令服务器的 DDoS 防御，以及在直接 P2P 连接失败时进行加密的 TURN Relay 中继。
- **STUN 服务器（Google、Cloudflare、Twilio）：** 仅用于模组获取您自身的公网 IP 与端口信息。
- **GitHub / jsDelivr：** 用于在模组启动时检查版本更新及获取当前服务器配置（`config.json`）。

这些第三方服务在其自有系统中所保留的记录及其隐私规范均受其各自的隐私政策管辖；**Safra 及其开发者对这些第三方提供商的数据处理行为不承担任何责任。**
