# Safra — 개인정보 처리방침

**최종 수정일:** 2026년 11월 14일

> ℹ️ **법적 고지:** 본 개인정보 처리방침의 공식적이고 법적 구속력을 갖는 원본은 [영문 버전](https://github.com/DeveloperKubilay/Safra/blob/assets/PRIVACY.md)입니다. 다른 언어로의 번역은 이용자의 편의와 정보 제공만을 위해 제공됩니다. 번역본과 영문 원본 사이에 불일치나 상충이 있는 경우 영문 버전이 우선합니다.

Safra는 중앙 전용 게임 서버를 대여하거나 구축할 필요 없이 플레이어가 직접 P2P(Peer-to-Peer) 연결을 통해 함께 플레이할 수 있도록 지원하는 마인크래프트 모드입니다. 당사는 광고, 통계 분석 또는 상업적 목적으로 **이용자의 데이터를 제3자에게 판매, 대여 또는 공유하지 않습니다.**

---

## 1. 처리하는 데이터 및 로그 보관 목적

모드가 기술적으로 원활히 구동되고, 플레이어 간 매칭을 수행하며, **DDoS 공격 및 악의적인 남용으로부터 인프라를 보호하고 법적으로 방어하기 위해** 오직 다음의 기술적 데이터만을 처리합니다:

- **IP 주소:** P2P 매칭 처리, 동일 IP로부터의 과도한 요청 제한(Rate-limiting), DDoS 공격 또는 악용 발생 시 서버 보안 방어를 위해 처리되며 서버 접속 로그에 기록됩니다.
- **임시 포트 정보:** 호스트와 참가 플레이어가 직접 연결을 맺을 수 있도록 세션 매칭 중에 처리됩니다.
- **세션 코드 및 선택적 월드 코드:** 올바른 플레이어를 해당 세션에 연결하기 위해 처리되며 서버 접근 로그에 포함됩니다.
- **릴레이 요청 및 RelayId:** 엄격한 NAT/CGNAT 환경 등 직접 P2P 홀펀칭이 실패할 경우 암호화된 TURN / Bedrock Relay 폴백을 형성하고 남용을 모니터링하기 위해 처리됩니다.
- **User-Agent (Safra, 마인크래프트, 모드 로더 및 Java 버전):** 공식적이고 호환 가능한 빌드에서 요청이 오는지 확인하고 디버깅을 지원하며 봇이나 공격 트래픽을 구분하기 위해 기록됩니다.
- **타임스탬프 및 Cloudflare `Ray` ID:** DDoS 공격이나 기술적 장애 발생 시 트래픽을 분석하기 위해 서버 접근 로그에 저장됩니다.

보안 및 DDoS 방어를 위해 보관되는 서버 접근 로그는 시스템 보안 유지 및 네트워크 공격에 대한 법적 방어에 필요한 기간 동안 보관됩니다.

---

## 2. 수집하거나 기록하지 않는 정보

Safra는 다음 정보를 **일절** 수집, 열람 또는 기록하지 않습니다:
- 비밀번호, 마인크래프트 / Microsoft 계정 자격 증명 또는 인증 토큰
- 개인 식별 또는 연락처 정보 (이름, 이메일 주소, 전화번호 등)
- 게임 내 채팅 메시지, 명령어, 음성 채팅 음성 데이터
- 사용 중인 다른 모드 목록, 월드 저장 파일(saves), 인벤토리 데이터 또는 게임 내 이벤트

## 3. P2P 연결, IP 노출 및 코드 보안 (면책 조항)

- **IP 및 포트 전달은 기술적으로 필수입니다:** Safra는 게임 트래픽을 플레이어 간에 직접(P2P) 전송합니다. 세션 코드를 공유받은 상대방이 내 게임에 접속하려면 상대방에게 귀하의 IP 주소와 포트가 필연적으로 전달되어야 합니다.
- **신뢰할 수 있는 친구와만 플레이하세요:** P2P 네트워킹 특성상 접속하거나 내 월드로 초대한 상대방은 귀하의 IP 주소를 확인할 수 있습니다. 신뢰할 수 없는 사람에게 코드를 공유하거나 공개적으로 게시하여 발생하는 **IP/포트 노출이나 잠재적인 네트워크 공격에 대해 Safra 및 개발자는 어떠한 책임도 지지 않습니다.** 반드시 신뢰할 수 있는 친구하고만 플레이하시기 바랍니다.
- **코드 예측 불가능성:** 세션 코드는 암호학적으로 안전한 난수 생성기를 사용하여 12자리(고정 코드 모드에서는 16자리)로 생성되며 $32^{12}$개 이상의 조합을 갖습니다. 이용자가 직접 코드를 공유하지 않는 한 제3자가 세션을 추측하거나 임의로 찾아내는 것은 이론적·현실적으로 불가능합니다.

## 4. 제3자 인프라 (면책 조항)

이용자의 데이터는 상업적 목적으로 제3자에게 이전되지 않으나, 모드의 정상적인 작동을 위해 다음의 기술 인프라 제공업체와 통신해야 합니다:
- **Cloudflare:** 시그널링 서버의 DDoS 방어 및 직접 P2P 연결 실패 시 암호화된 TURN 릴레이 전달을 위해 사용됩니다.
- **STUN 서버 (Google, Cloudflare, Twilio):** 모드가 사용자의 외부 공인 IP와 포트를 확인할 수 있도록 돕는 용도로만 사용됩니다.
- **GitHub / jsDelivr:** 실행 시 모드 업데이트 확인 및 최신 서버 설정(`config.json`) 조회를 위해 사용됩니다.

이러한 제3자 서비스가 자체 시스템에 보관하는 기록과 개인정보 처리 관행은 해당 업체의 자체 정책을 따르며, **Safra 및 개발자는 제3자 제공업체의 데이터 처리 관행에 대해 책임을 지지 않습니다.**
