# 이 시스템은 어떻게 작동하나요?

Omegle 이나 WhatsApp 같은 앱은 보통 중간에 서버를 계속 두지 않고 통신합니다. 이 시스템도 비슷한 아이디어로 동작합니다.

인터넷 제공업체가 TCP 포트 개방은 막아도 UDP 포트는 허용할 수 있습니다.

이 모드에서는 원래 TCP 로 동작하는 Minecraft 서버 통신을 UDP 위로 실어서 상대방에게는 TCP 처럼 보이게 합니다.

그래서 트래픽이 릴레이 서버를 거치지 않아도 친구와 무료로 부드럽게 플레이할 수 있습니다.

예를 들어 비슷한 모드에서는:

`내 컴퓨터 (이스탄불) -> 릴레이 서버 (프랑크푸르트) -> 친구 컴퓨터 (이스탄불)`

이 모드에서는:

`내 컴퓨터 (이스탄불) -> 친구 컴퓨터 (이스탄불)`

게임 트래픽 중간에 서버가 없습니다.

통신은 오직 너와 친구 사이에서만 이루어집니다.

이 모드가 서버를 사용하는 이유는 양쪽이 서로의 IP 주소를 찾을 수 있게 하기 위해서뿐입니다.

## 보안

- CodeQL 스캔을 사용합니다
- CurseForge 같은 플랫폼이 새 버전을 스캔할 수 있습니다
- 빌드를 직접 확인할 수 있습니다
- 빌드는 내 컴퓨터에서 수동 업로드하는 대신 GitHub Actions 로 업로드됩니다
