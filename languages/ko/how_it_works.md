# 이 시스템은 어떻게 작동하나요?

WhatsApp(통화 시), Omegle, 토렌트 같은 플랫폼은 모든 트래픽을 중앙 서버에 집중시키는 대신 **P2P (Peer-to-Peer / P2P 직접 연결)** 기술을 사용합니다. 수많은 플레이어의 게임 데이터를 중앙 서버로 중계하면 심각한 지연 시간(렉)이 발생하고 막대한 서버 호스팅 비용이 들기 때문입니다.

### 구체적으로 어떻게 작동하나요?

1. 일반적으로 가정용 인터넷은 공용 포트가 열려 있지 않습니다 (IPv4 주소 고갈 및 통신사의 CGNAT 사용으로 인해 외부에서 직접 포트를 열 수 없습니다).
2. 하지만 웹사이트에 접속하거나 외부로 요청을 보낼 때 공유기/통신사는 외부와 통신하기 위해 임시 출력 포트를 열어줍니다.
3. 이 모드는 바로 이 원리를 이용합니다: 마치 구글 같은 웹사이트에 접속하려는 것처럼 동작하여 임시 포트 정보를 가져옵니다(메시지는 보내지 않음). 그리고 여러분의 포트 정보를 친구에게, 친구의 포트 정보를 여러분에게 전달합니다. 즉, *"웹사이트에 접속할게"* 하고 열린 포트를 통해 친구와 직접 연결되는 방식입니다.
4. 연결이 완료되면 게임 트래픽은 **중간에 어떠한 서버도 거치지 않고**, 나와 친구의 컴퓨터 사이에서 직접(P2P) 전송됩니다.

---

### 연결 방식 비교

예를 들어 비슷한 모드에서는:

`내 컴퓨터 (이스탄불) -> 릴레이 서버 (프랑크푸르트) -> 친구 컴퓨터 (이스탄불)`

이 모드에서는:

`내 컴퓨터 (이스탄불) -> 친구 컴퓨터 (이스탄불)`

중간에 릴레이 서버가 전혀 없으며, 통신은 오직 둘 사이에서만 직접 이루어집니다.

## 보안

- CodeQL 스캔을 사용합니다
- CurseForge 같은 플랫폼이 새 버전을 스캔할 수 있습니다
- 빌드를 직접 확인할 수 있습니다
- 빌드는 내 컴퓨터에서 수동 업로드하는 대신 GitHub Actions 로 업로드됩니다
