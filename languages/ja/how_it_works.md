# この仕組みはどう動くの？

Omegle や WhatsApp のようなアプリは、通常ずっとサーバーを間に置かずに通信します。この仕組みもそれに近い考え方です。

インターネット回線によっては TCP ポートの開放はできなくても、UDP ポートは使える場合があります。

この Mod では、通常は TCP で動く Minecraft サーバーの通信を UDP 上で運び、相手側には TCP のように見せています。

これにより、通信がリレーサーバーを通らなくても、友達と無料でスムーズに遊べます。

たとえば似たような Mod では:

`あなたのPC（イスタンブール） -> リレーサーバー（フランクフルト） -> 友達のPC（イスタンブール）`

この Mod では:

`あなたのPC（イスタンブール） -> 友達のPC（イスタンブール）`

ゲーム通信の途中にサーバーはありません。

通信はあなたと友達の間だけで行われます。

この Mod がサーバーを使うのは、双方がお互いの IP アドレスを見つけるためだけです。

## セキュリティ

- CodeQL スキャンを使用しています
- CurseForge のようなプラットフォームが新しいバージョンをスキャンする場合があります
- ビルド内容を確認できます
- ビルドは自分のPCから手動で上げるのではなく GitHub Actions でアップロードしています
