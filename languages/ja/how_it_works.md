# この仕組みはどう動くの？

WhatsApp（通話時）や Omegle、BitTorrent などのアプリは、すべての通信を中央サーバー経由にするのではなく、**P2P（Peer-to-Peer / ピアツーピア）** 技術を使用しています。何万人ものプレイヤーのゲームデータを中央サーバー経由で通信させると、遅延（ラグ）が大きくなり、莫大なサーバー費用が発生してしまうためです。

### 具体的な仕組みは？

1. 通常、家庭用インターネットでは外部からポートを開放することができません（IPv4 アドレスの枯渇やプロバイダの CGNAT により、外部から直接ポートを開けられません）。
2. しかし、Web サイトにアクセスしたり外部へ通信を行ったりする際、ルーター/プロバイダは一時的に外部への出口ポートを開きます。
3. この Mod はその仕組みを利用し、まるで Google などの Web サイトにアクセスするかのように振る舞って一時的なポートを取得します（メッセージ自体は送信しません）。そして、取得したポート情報を友達に渡し、友達のポート情報をあなたに渡します。つまり、*「Web サイトにアクセスする」* と見せかけて開いたポートを使って、直接友達と接続します。
4. 一度接続が確立されると、ゲームの通信は**途中にサーバーを一切挟まず**、あなたと友達の PC 間で直接（P2P）やり取りされます。

---

### 接続の違い

たとえば似たような Mod では:

`あなたのPC（イスタンブール） -> リレーサーバー（フランクフルト） -> 友達のPC（イスタンブール）`

この Mod では:

`あなたのPC（イスタンブール） -> 友達のPC（イスタンブール）`

途中に中継サーバーはなく、通信はあなたと友達の間だけで直接行われます。

## セキュリティ

- CodeQL スキャンを使用しています
- CurseForge のようなプラットフォームが新しいバージョンをスキャンする場合があります
- ビルド内容を確認できます
- ビルドは自分のPCから手動で上げるのではなく GitHub Actions でアップロードしています
